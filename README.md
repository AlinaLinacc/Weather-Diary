# Weather Diary - Дневник погоды

**Автор:** Алина Серикова

## Описание программы

Weather Diary - это современное приложение с графическим интерфейсом для ведения дневника погоды. Программа позволяет удобно отслеживать и анализировать погодные условия.

### Основные возможности

-  **Добавление записей** - Быстрое добавление информации о погоде
-  **Фильтрация** - По дате и температуре
-  **Сохранение/загрузка** - В формате JSON
-  **Управление** - Удаление записей (одиночное или массовое)
-  **Статистика** - Отображение количества записей
-  **UI с иконками** - Интуитивно понятный интерфейс

### Технологии

- Python 3.7+
- Tkinter (GUI)
- JSON (хранение данных)

## Руководство по использованию
1. Добавление записи

Дата - введите в формате ГГГГ-ММ-ДД (пример: 2026-05-15)
Температура - введите число (можно с точкой, пример: 23.5)
Описание - краткое описание погоды (не пустое)
Осадки - отметьте флажок, если есть осадки
Нажмите "Добавить запись"
2. Фильтрация записей

По дате:

Введите дату в поле "По дате"
Нажмите "Применить"
Результат: покажутся записи только за этот день
По температуре:

Введите минимальную температуру
Нажмите "Применить"
Результат: покажутся записи с температурой выше указанной
Сброс фильтра:

Нажмите "Сбросить фильтр"
3. Работа с файлами

Сохранение:

Нажмите "Сохранить в JSON"
Выберите папку и имя файла
Данные сохранятся в формате JSON
Загрузка:

Нажмите "Загрузить из JSON"
Выберите ранее сохраненный файл
Данные загрузятся в программу
4. Управление записями

Удалить одну запись:

Дважды кликните по записи в таблице
Подтвердите удаление
Удалить все записи:

Нажмите "Очистить все записи"
Подтвердите действие

2026-05-14 | 12.5 | Пасмурно | Есть осадки
2026-05-15 | 19.0 | Ясно | Нет осадков

# 2. Отфильтруйте дождливые дни
# Поставьте фильтр "Осадки: Да" (в следующей версии)

# 3. Сохраните данные в JSON

Пример 2: Анализ погоды

// Экспортированные данные для анализа
[
    {"date": "2026-01-15", "temperature": -15.0, "description": "Сильный мороз", "precipitation": false},
    {"date": "2026-01-16", "temperature": -12.0, "description": "Снегопад", "precipitation": true},
    {"date": "2026-01-17", "temperature": -8.0, "description": "Облачно", "precipitation": false}
]

Пример 3: Фильтрация по температуре

Исходные данные:
- 05.05.2026: 8°C (холодно)
- 06.05.2026: -2°C (мороз)
- 07.05.2026: 25°C (жара)

Фильтр: Температура > 10°C
Результат: только 07.05.2026 (25°C)

## Структура JSON файла
[
    {
        "date": "ГГГГ-ММ-ДД",      // Дата в стандартном формате
        "temperature": число,      // Температура в °C
        "description": "текст",    // Описание погоды
        "precipitation": boolean   // true - есть осадки, false - нет
    }
]
